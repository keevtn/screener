## How to read a node
Each feature note names its **Anchor** (file:symbol), a plain-language **Purpose**, and the dependency in words: **Receives from** an upstream node *via a table* (with why), and **Feeds** a downstream node *via a table*. Tables (in [[12 Tables - MOC|12 Tables]]) are the hub nodes, so the graph reads feature → table → feature.

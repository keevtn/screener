## Color the graph by stage

A minimal `.obsidian/graph.json` with per-folder color groups is included. If Obsidian does not pick it up, set them manually: **Settings → Graph view → Groups → New group**, and add one query per stage:

```
path:"00 Spine"
path:"01 Ingest"
path:"02 Enrich"
path:"03 Score"
path:"04 Signal"
path:"05 Grade"
path:"06 Gates"
path:"07 Trader"
path:"08 Panel"
path:"09 Agents"
path:"10 Marketdata"
path:"11 API"
path:"12 Tables"
path:"13 Ops"
```

Give each a distinct color. The folders double as the graph's color groups.
